# Bundled sample quality and curation

The catalog contains 345 bundled PCM WAV one-shots, including one CC BY 4.0 re-performance by Arthur DnB. Run `npm.cmd run audit:samples` to verify every file against its catalog SHA-256 and inspect peak level, whole-file RMS, lead-in, DC bias and duration. `--all` prints measurements for every file. The audit is diagnostic: a near-full-scale transient is not necessarily clipped, and a quiet shaker may be intentional.

Audit on 2026-09-28: 344 files passed format and hash checks. The report flagged 45 for review: 37 have peaks at or above 0.999, one is below 0.05 peak, and nine have more than 25 ms of lead-in. No file exceeded the 0.03 DC threshold. These counts overlap. Source URLs are absent from 111 Lo-Fi Vol. 2 catalog records; redistribution of those and the 188 UDNB files was confirmed by the project owner on 2026-09-28, but upstream author/source metadata should still be added when available. The audit does not prove subjective sound quality or legal provenance.

Bundled sounds are prepared in memory on first load: dead air is trimmed with a 2 ms lead-in, 120 ms transient RMS is balanced within a per-role peak ceiling, and a short edge fade limits cuts. Uploaded WAVs are left untouched. Prepared PCM is shared by live Preview and WAV export. Existing saved projects with embedded PCM retain their stored audio until a sound is reselected.

The **Think Passage 2 · +6 st** bundled preset uses Arthur DnB's original Think-style break re-performance. It uses the complete 2.23 s Passage 2 clip selected in the speed audition, repitched by six semitones to a 1.577 s playback file; it does not use the separately matched 0.758 s single-hit extraction. It is listed as **CC BY 4.0** in the sample catalog and credits page. Select this kit when generating a Jungle or DnB pattern to route the genre's percussion events through the vocal chop.

Three focused UDNB kits now ship for jungle, liquid DnB and rollers. They use short kicks, snares, hats and percussion from the cleared collection. The sound menu promotes kit selections in a Featured group while retaining the complete catalog and user uploads. Kit selection remains subjective; the next curation pass should include matched-level listening comparisons across the deployed browser and common headphones/monitors, then document any rejected one-shots and replacement choices.
