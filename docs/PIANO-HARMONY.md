# Piano harmony and sound

The independent **Piano chords** generator now shares a seeded harmony plan with Bass and Melody. A one- or two-bar pattern has two chord changes per bar; longer patterns change once per bar. The chosen genre's progression family supplies scale degrees. The piano engine derives diatonic sevenths and, as Complexity rises, ninths and extra color tones. It scores inversions for short upper-voice movement, register, and spacing. When a generated bassline already exists, the piano leaves out its low root so the two parts have room.

Genre families affect articulation: sustained pads of chords in liquid DnB and downtempo, offbeat stabs in garage, pulses in boom bap, and shorter accents in faster or fractured styles. Key and Scale constrain every chord note; the fallback for short scales removes duplicate pitches. The generator is deterministic for identical settings and respects the generated track's locked notes through the existing editor.

The default new piano track uses 26 original FLAC recordings selected from [FreePats Upright Piano KW](https://github.com/freepats/upright-piano-KW), published under CC0 1.0. Source and license details are in [the bundled credits](../public/piano/CREDITS.md). The browser decodes only the soft/strong recordings needed by the current notes. The same decoded assets feed pattern Preview, song playback, and WAV export; the bank is distributed with the site and is not copied into project JSON. A project can instead use the procedural built-in tone or a user-uploaded single-note WAV. Uploads are embedded in project files; set the sample's MIDI root to its actual recorded note. A single note stretched across several octaves will sound less natural than the multi-sample bank. The supplied `piano-one-shot-key-c-major_130bpm.wav` is suitable for a personal audition, but the source appears clipped in its left channel and has one short note, so it is not shipped as the default bank.

This is a rule-based phrase composer, not a jazz improviser or chord recognition model. Its chord symbols are guidance for the generated voicing and are most useful as a starting point for tracker editing. Secondary dominants, borrowed chords outside the selected scale, and longer form-aware harmonic rhythm would require a later explicitly chromatic mode and listening validation.

To inspect the local A/B report, run `npm.cmd run build` then `node scripts/piano-audition.mjs "C:\path\to\your-piano-note.wav"` and open `test-results/piano-audition/index.html`. The report compares the procedural fallback with that uploaded note. To hear the shipped upright bank, generate Piano chords in the app and use Preview or Export WAV.
